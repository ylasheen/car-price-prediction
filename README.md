# 🚗 Used Car Price Prediction

A Machine Learning web app that predicts used car prices using XGBoost.

## 🌐 Live Demo
> Coming soon on Streamlit Cloud

## 📊 Dataset
- **Source:** [Craigslist Cars & Trucks Data](https://www.kaggle.com/datasets/austinreese/craigslist-carstrucks-data)
- **Size:** 426,880 rows × 26 columns
- **Platform:** Craigslist USA

## 🤖 Model
- **Algorithm:** XGBoost Regressor
- **R2 Score:** 0.92
- **Training Data:** 300,000+ cars

## ⚙️ Features Used
- 📅 Year
- 🛣️ Odometer
- 🏭 Manufacturer
- 🔧 Condition
- ⛽ Fuel Type
- 🔄 Transmission
- 🚙 Drive
- 🚗 Type
- 📍 State

## 🛠️ Tech Stack
- Python
- XGBoost
- Scikit-learn
- Streamlit
- Pandas
- Plotly

## 🚀 Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
